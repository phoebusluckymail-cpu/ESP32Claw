# ESP32Claw
为ESP32开发openclaw可以进行控制的skillls，探索智能物联网的可能性。
---
## esp32-light
通过局域网UDP通信协议连接ESP32（MicroPython固件），实现Agent指令对物理GPIO引脚的控制。实现了基于本地大模型，构建隐私安全的自然语言实时控制、场景设置、程序编写，验证了在消费级平台上构建本地物联网智能终端AIoT的可能性、探索出未来的云边端协同AIoT智能机器人架构。
  
**技能注意**：
1. 为确保系统的可靠性，避免UDP丢包问题，esp32端设计了返回系统和延迟系统，执行完成后返回信息，openclaw会自动读取并回复给用户，若返回信息超时则再次尝试执行。  
2. 为实现降低成本和隐私安全的效果，推荐使用本地大模型，实测qwen3.5 4B模型即可实现技能使用和场景设置、组合技能程序编写。  
3. 结合openclaw的本地记忆功能、客户可以在消费级平台（8GB以上显卡）实现本地智能家庭AIoT的布置。  
4. 本地模型布置推荐llama.cpp, 性能相比ollama提升近五倍，使用Q4_K_M量化大幅降低模型大小，实测RTX5060 8GB 显卡独占的情况下最高支持9B模型。
5. 本地大模型对于复杂规划能力较弱，可以引入云端大模型，实现云边端协同AIoT智能机器人，云端大模型进行复杂任务规划，端侧中模型负责实时技能控制和隐私脱敏，边侧小模型实时感知和动作系统。
  
**产品亮点**：①消费级可用，市场潜力巨大 ②跨生态互通：Skills层统一控制，摆脱生态，万物协作 ③自然语言实时编程，个性化技能和场景应用。  
**解决痛点**：①厂商生态封闭设备难联动 ②预设自动化功能固化，智能程度低 ③纯云端方案隐私与延迟问题。

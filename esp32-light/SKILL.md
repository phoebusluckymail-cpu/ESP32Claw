# ESP32 灯光控制 Skill

通过发送 UDP 网络命令，控制指定 IP 地址的 ESP32 设备上的 LED 灯。

## 适用场景

- 当你需要打开或关闭连接到 ESP32 的 LED 灯时
- 当你想要查询 LED 灯的当前状态（开/关）时
- 智能家居灯光控制

## 配置要求

### 网络环境
- 电脑和 ESP32 必须在同一个局域网内
- ESP32 的 IP 地址需要固定（代码中已设置为 192.168.43.128）

### ESP32 端准备
确保 ESP32 上已经烧录了对应的接收端代码，并且：
- WiFi 已连接到热点 `LYH`
- UDP 服务正在端口 `7788` 上监听
- LED 连接在 GPIO 2 引脚

## 使用方法

### 命令行调用

当你需要控制 ESP32 上的灯时，请使用以下命令格式：

**开灯：**

```bash
led_control.py on
```

**关灯：**

```bash
led_control.py off
```

**查询状态：**

```bash
led_control.py status
```

用户可以说：
- 开灯："帮我打开 ESP32 的灯" “开灯”

- 关灯："把灯关掉" “关灯”

  AI 会理解这些意图并自动调用对应的命令。

## 技术细节

### 通信协议
- **协议**: UDP
- **ESP32 IP**: 192.168.43.128（固定）
- **ESP32 端口**: 7788
- **命令格式**: 字符串文本

### 命令映射

| 用户意图 | 发送命令    | ESP32 回复                  | 回复用户                 |
| -------- | ----------- | --------------------------- | ------------------------ |
| 开灯     | `light on`  | `LED is ON`                 | 好的，灯打开了           |
| 关灯     | `light off` | `LED is OFF`                | 好的，灯关闭了           |
| 查询状态 | `status`    | `LED is ON` 或 `LED is OFF` | 灯是开着的 或 灯是关着的 |

### 超时设置
- 等待回复超时时间: 2 秒
- 超时后提示"无回复"

## 故障排除

### 收不到回复
1. 检查 ESP32 是否已连接 WiFi
2. 确认 ESP32 的 IP 是否为 `192.168.43.128`
3. 检查电脑和 ESP32 是否在同一局域网
4. 确认 ESP32 上的 UDP 服务正在运行

### 连接失败
1. 确保手机热点 `LYH` 已开启
2. 检查 WiFi 密码是否正确
3. 尝试重启 ESP32
